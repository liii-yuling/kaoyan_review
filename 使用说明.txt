考研定制化复习系统
====================

版本：20260917-010002
打包时间：2026-09-17 01:00:02

怎么打开
--------
方式一（推荐）：有 Node.js 的话，双击「启动.cmd」，会自动打开浏览器。
                用这种方式打开，数据刷新后不会丢。

方式二：直接双击 index.html。零安装，但部分浏览器在这种方式下会禁用
        本地存储，刷新页面数据就会丢。页面左下角会明确显示当前状态，
        看到"临时存储模式"请立刻到「设置与备份」导出备份。

数据在哪里
----------
你的错题、掌握度、练习与考试记录、导入的题库、绑定的视频，
全部保存在你当前使用的浏览器里，不会上传到任何服务器。
这也意味着：换浏览器、换电脑、清理浏览器数据都会丢。
请养成习惯——每周到「设置与备份 → 导出完整备份」存一份 JSON 文件。

题库来自哪里
------------
题库分三层，合并优先级是：内置题库 > 共享题库 > 个人题库。
  · 内置题库：随程序自带的四科真题与习题；
  · 共享题库：本网站已带 535 题，由发布者统一维护，你刷新页面就会自动拿到最新的一批；
  · 个人题库：你自己在「题库导入」页传的题，只存在你的浏览器里，别人看不到。

今日计划
--------
发布者还没有发布每日计划。发布后你刷新页面就能看到。

你的数据
--------
你的错题本、掌握度、打勾进度、考试成绩都存在你自己的浏览器里，
发布者看不到，也不会上传到任何服务器。
所以：别用无痕模式打开，也别清理浏览器数据——会丢。
建议每周到「设置与备份 → 导出完整备份」存一份 JSON 文件。

从哪里开始
----------
1. 进「设置与备份」填姓名、目标院校、考试日期；
2. 进「错题本 → 上传错题」，把做错的题拍照或粘贴进去；
3. 进「定制化推送」，按系统推送的薄弱考点刷题；
4. 进「历年真题（英语一）」看真题，每道题点「查看答案与详解」；
5. 进「题库导入」加自己的题库。

详细说明见 README.md 和「使用说明」页面。
